# Connection performance drivers (synthetic note)

This is a fictional summary written for SynapSI examples.

Analysis of a year of connection data attributes most missed connections to
inbound arrival delay (about 70%), gate-to-gate distance (about 15%), and
security re-screening for international arrivals (about 10%). Check-in channel
was not included as a variable in this analysis.

Frequent-flyer status correlates with lower missed-connection rates, likely
because these passengers book longer connections.
